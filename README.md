# Srirag Portfolio

A GitHub-style personal portfolio built with React + Vite.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Wouter
- Lucide React

## Features

- GitHub-like layout (header, sidebar, profile sections)
- Route-based tabs: Overview, Skills, Projects, Education, Experience
- Data-driven cards for skills, projects, and education
